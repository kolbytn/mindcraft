# Contributing Guide

We welcome contributions to Mindcraft! Please follow these guidelines to get started:

1. **Fork the Repository**: Create a fork under your own GitHub account.
2. **Clone the Fork**: Clone your fork locally.
3. **Create a Topic Branch**: Create a branch for your changes (e.g., `feat/add-feature-xyz` or `fix/bug-abc`).
4. **Follow Commit Standards**: Write clear commit messages using Conventional Commits.
5. **Submit a Pull Request**: Submit a PR back to the main repository's default branch.
