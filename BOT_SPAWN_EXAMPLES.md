## 🎮 Pro Tips

**Start Small:**
- Begin with 1-2 bots to learn the system
- Watch how they coordinate in chat
- Check status with `/msg andy list bots`

**Clean Up:**
- Kill bots when done: `/msg andy kill all bots`
- Check pool status: `/msg andy check bot pool status`
- Kill specific bot: `/msg andy kill gatherer-1`

**Monitor Progress:**
- List active bots: `/msg andy list bots`
- Check bot status: `/msg andy bot status`
- View survival progress: `/msg andy survival progress`

**Survive Mode:**
- Use milestones for structured progression
- Each milestone spawns appropriate bots automatically
- Bots coordinate via in-game chat

**Orchestration:**
- Use "orchestrate" keyword for complex builds
- Spawns Scout→Architect→Builder→Tester automatically
- Best for large construction projects

## ⚡ Quick Start

**Easiest way to test:**
```
/msg andy survive and get wooden tools
```
This will:
1. Spawn gatherer-1 (collects wood)
2. Spawn crafter-1 (crafts tools)
3. They coordinate automatically
4. Complete milestone and report back

**Watch them work:**
- Bots chat in-game to coordinate
- Check their progress: `/msg andy list bots`
- Kill when done: `/msg andy kill all bots`
